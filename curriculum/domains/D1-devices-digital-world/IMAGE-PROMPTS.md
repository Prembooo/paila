# Domain 1 — AI Image Generation Prompts

Use these prompts in any AI image tool (e.g. an image generator) to make richer, friendlier illustrations for the Domain 1 lessons. The lessons already work with the built-in SVG diagrams; these are for **optional richer art**.

**How to add a generated image:**
1. Generate the image, save it as PNG (e.g. `devices-photo.png`).
2. Put the file in `curriculum/shared/figures/`.
3. In the lesson, reference it like the SVGs: `![alt text](figures/devices-photo.png)`.
4. Rebuild the site (`node build.js`). The builder copies and shows PNG/JPG too.

**Style guidance for all images:** warm, friendly, simple flat illustration; rural Nepal context where people appear; bright, high-contrast colors; clear single subject; minimal text in the image (label in the lesson instead); inclusive of teenage boys and girls.

---

## D1-M1 — What Is a Computer?
> "A simple, friendly flat illustration showing four devices side by side on a clean background: a desktop computer, a laptop, a tablet, and a smartphone. Bright colors, clear shapes, no text labels, suitable for low-literacy teenage learners."

Alternative (context): "A rural Nepali community computer lab with teenage students looking at a desktop computer, warm and welcoming, flat illustration style, no text."

## D1-M2 — Parts of a Computer
> "A clear flat illustration of a desktop computer setup with parts visually separated: monitor, system unit/tower, keyboard, mouse, webcam, and a storage drive. Friendly bright colors, simple shapes, space around each part so labels can be added later, no text."

## D1-M3 — Hardware, Software & the Operating System
> "A simple three-layer stack illustration: bottom layer shows physical computer parts (hardware), middle layer shows a control panel (operating system), top layer shows colorful app icons (software). A happy teenager points at the top layer. Flat style, bright, minimal text."

## D1-M4 — First Hands-On: Using a Computer
> "A friendly step-by-step style illustration of a teenager turning on a desktop computer in a simple classroom: pressing the power button, using the mouse, typing on the keyboard. Warm, encouraging, flat illustration, rural Nepal setting, no text."

---

_Keep generated images small (web-optimized, under ~200 KB each) so the site stays fast and works on low-bandwidth lab connections and phones._
