# Capstone Assessment & Self-Check
# क्यापस्टोन मूल्यांकन र स्व-जाँच

> Behavior-based, observable checks. They match the outcome wording in
> `architecture/outcomes.md` (O01–O12). A facilitator confirms each by
> watching the learner do it. Tone is safety-first, never fear-based.

---

## English version

### How to use
The capstone (D6-M4) shows skills from all six domains. Use this list to
confirm each outcome. Mark a box only when you see the learner do it.
If a learner needs guided support, they still perform each skill
themselves.

### Observable check items (O01–O12)

| ID | Outcome (short) | Observable check (what you watch for) | ☐ |
|---|---|---|---|
| **O01** | Operate a device for a basic task | Learner powers a device on/off and opens a named app without help | ☐ |
| **O02** | Explain the internet; reach info | Learner opens a browser and reaches a named site/app | ☐ |
| **O03** | Search and refine terms | Learner finds a target answer and improves one weak search | ☐ |
| **O04** | Facts vs opinions; source-trust check | Learner labels 3 items fact/opinion and runs the 4-question check | ☐ |
| **O05** | Spot misinformation; cross-check | Learner flags a misleading claim and names 2 independent checks | ☐ |
| **O06** | Use AI and verify its answers | Learner asks the AI, then verifies the answer against 2 sources | ☐ |
| **O07** | Protect info; digital footprint | Learner names what to keep private and one footprint example | ☐ |
| **O08** | Recognize scams/synthetic media | Learner spots a scam warning sign and states the safe response | ☐ |
| **O09** | Responsible social media; identity | Learner picks the respectful response and one identity action | ☐ |
| **O10** | Recognize manipulation; cope | Learner names a design trick and one coping step | ☐ |
| **O11** | Use mobile money safely | Learner refuses a fake request and verifies via a trusted channel | ☐ |
| **O12** | Plan and complete a capstone | Learner produces a cited, verified capstone artifact | ☐ |

### Capstone-specific checks (D6-M4)
- [ ] Artifact is in Nepali or the learner's first language.
- [ ] Artifact **cites at least 2 sources**.
- [ ] Learner **describes the steps taken to verify** the information (SP-3).
- [ ] Learner does a **privacy check**: no personal/sensitive info before sharing.
- [ ] Artifact shows **≥1 observable skill from each domain D1–D6**.
- [ ] If an alternative format is used (poster, talk, audio, drawing), it
      still shows the required skills, sources, and verify steps.
- [ ] If the learner needed guided support, they still performed each skill.

### Learner self-check (tick what is true)
- ☐ I made a researched answer or short explainer on my topic.
- ☐ I cited two sources.
- ☐ I wrote the steps I used to verify the facts.
- ☐ I removed personal or sensitive information before sharing.
- ☐ I showed one skill from each of the six domains.

### Project-theme selection (how it works)
- **Present in Nepali first.** Show the theme list in Nepali before any
  project begins (from `shared/project-themes.md`).
- **Select or change freely.** A learner may pick a theme, or change it
  later, without losing earlier progress.
- **Default if none.** If a learner does not choose, assign **TH-01
  Football** so the project can proceed.
- **Off-list / unsafe themes.** Allow a learner-proposed theme only if it
  has no personal/sensitive info and is safety-conformant. Otherwise,
  kindly redirect the learner to the theme list. No shame, just a calm
  redirect.

## नेपाली संस्करण

### कसरी प्रयोग गर्ने
क्यापस्टोन (D6-M4) ले छवटै डोमेनका सीप देखाउँछ। यो सूचीले हरेक परिणाम
पुष्टि गर्छ। विद्यार्थीले गरेको देखेपछि मात्र बाकस चिन्ह लगाउनुहोस्।
मार्गदर्शित सहयोग चाहिए पनि विद्यार्थी हरेक सीप आफैं गर्छन्।

### देखिने जाँच बुँदा (O01–O12)

| ID | परिणाम (छोटो) | देखिने जाँच (के हेर्ने) | ☐ |
|---|---|---|---|
| **O01** | उपकरणमा आधारभूत काम | सहयोगविना उपकरण अन/अफ गरी तोकिएको एप खोल्छन् | ☐ |
| **O02** | इन्टरनेट बुझ्ने; जानकारीमा पुग्ने | ब्राउजर खोलेर तोकिएको साइट/एपमा पुग्छन् | ☐ |
| **O03** | खोज्ने र शब्द सुधार्ने | लक्षित जवाफ भेट्छन् र एउटा कमजोर खोज सुधार्छन् | ☐ |
| **O04** | तथ्य/विचार; स्रोत जाँच | ३ कुरा तथ्य/विचार छुट्याई ४-प्रश्न जाँच चलाउँछन् | ☐ |
| **O05** | गलत सूचना चिन्ने; क्रस-चेक | भ्रामक दाबी चिनाई २ स्वतन्त्र जाँच बताउँछन् | ☐ |
| **O06** | AI प्रयोग र जवाफ जाँच | AI सोधेर जवाफ २ स्रोतमा जाँच्छन् | ☐ |
| **O07** | जानकारी जोगाउने; फुटप्रिन्ट | के गोप्य राख्ने र एउटा फुटप्रिन्ट उदाहरण भन्छन् | ☐ |
| **O08** | ठगी/नक्कली मिडिया चिन्ने | ठगीको चिन्ह चिनाई सुरक्षित प्रतिक्रिया भन्छन् | ☐ |
| **O09** | जिम्मेवार सामाजिक सञ्जाल; पहिचान | आदरपूर्ण प्रतिक्रिया र एउटा पहिचान काम छान्छन् | ☐ |
| **O10** | चलाखी चिन्ने; सामना | एउटा डिजाइन चाल र एउटा सामना उपाय भन्छन् | ☐ |
| **O11** | मोबाइल पैसा सुरक्षित प्रयोग | नक्कली अनुरोध अस्वीकार गरी भरपर्दो माध्यमबाट जाँच्छन् | ☐ |
| **O12** | क्यापस्टोन योजना र पूरा | स्रोत उद्धृत गरी, जाँचिएको क्यापस्टोन रचना बनाउँछन् | ☐ |

### क्यापस्टोन-विशेष जाँच (D6-M4)
- [ ] रचना नेपाली वा विद्यार्थीको मातृभाषामा छ।
- [ ] रचनाले **कम्तीमा २ स्रोत उद्धृत** गर्छ।
- [ ] विद्यार्थीले जानकारी **जाँच्न गरेका चरण बताउँछन्** (SP-3)।
- [ ] बाँड्नुअघि **गोपनीयता जाँच**: व्यक्तिगत/संवेदनशील जानकारी छैन।
- [ ] रचनाले **हरेक डोमेन D1–D6 बाट कम्तीमा एक देखिने सीप** देखाउँछ।
- [ ] वैकल्पिक ढाँचा (पोस्टर, भाषण, अडियो, चित्र) भए पनि चाहिने सीप,
      स्रोत र जाँच चरण देखाउँछ।
- [ ] मार्गदर्शित सहयोग चाहिए पनि विद्यार्थीले हरेक सीप आफैं गरे।

### विद्यार्थी स्व-जाँच (साँचो भएकोमा चिन्ह)
- ☐ मैले आफ्नो विषयमा खोजिएको जवाफ वा छोटो व्याख्या बनाएँ।
- ☐ मैले दुई स्रोत उद्धृत गरेँ।
- ☐ मैले तथ्य जाँच्न प्रयोग गरेका चरण लेखेँ।
- ☐ बाँड्नुअघि व्यक्तिगत वा संवेदनशील जानकारी हटाएँ।
- ☐ मैले छवटै डोमेनबाट एक-एक सीप देखाएँ।

### परियोजना विषय छनोट (कसरी चल्छ)
- **पहिले नेपालीमा देखाउने।** परियोजना सुरु हुनुअघि विषय सूची नेपालीमा
  देखाउनुहोस् (`shared/project-themes.md` बाट)।
- **स्वतन्त्र छनोट/परिवर्तन।** विद्यार्थीले विषय छान्न वा पछि बदल्न
  सक्छन्, अघिको प्रगति नगुमाई।
- **नछाने पूर्वनिर्धारित।** विद्यार्थीले नछाने **TH-01 फुटबल** दिनुहोस्,
  ताकि परियोजना अघि बढोस्।
- **सूचीबाहिर / असुरक्षित विषय।** विद्यार्थीले सुझाएको विषय व्यक्तिगत/
  संवेदनशील जानकारी नभए र सुरक्षा-अनुकूल भए मात्र स्वीकार गर्नुहोस्।
  नभए नम्रतापूर्वक विषय सूचीमा फर्काउनुहोस्। लाज होइन, शान्त मार्गदर्शन।
