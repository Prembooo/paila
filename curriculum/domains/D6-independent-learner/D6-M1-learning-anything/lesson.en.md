# Learning Anything

## 1. Learning Goal (सिकाइ लक्ष्य)

By the end, you can name the steps of self-learning.
You can use a simple loop to learn something new.

## 2. Let's Learn (सिकौं)

You can now use a computer, the internet, and AI.
Together, these let you learn almost anything.

Self-learning works best as a simple loop.
You ask, you check, you practise, then you ask again.

![Ask a question, check the answer, practise, then ask a better one.](figures/learning-loop.svg)

First, ask a clear question about what you want.
Then find an answer and check it with a second source.

Next, practise the new skill in a small way.
Practice turns a fact into something you can really do.

AI can help at each step, but it is not always right.
**AI literacy:** always check its answer before you trust it.

## 3. Look and Name (हेरौं र नाम भनौं)

| Step | What you do |
|---|---|
| 1. Ask | Write a clear question about your goal. |
| 2. Check | Find an answer; confirm with a second source. |
| 3. Practise | Try the skill in a small, real way. |
| 4. Ask again | Use what you learned to ask a better question. |

## 4. Practice (अभ्यास)

Do this with your facilitator near.

1. Choose one small thing you want to learn.
2. Write one clear question about it.
3. Say how you would check the answer.
4. Name one way you would practise it.

**Success:** you wrote a question and named a way to check and practise.

## 6. Activity (क्रियाकलाप)

Pick a topic you like — for example football, a song, farming, or your village. Any topic is fine.
Use the loop to start learning one new thing about your topic.
Write your question, where you would check, and how you would practise.
For example: "How do I do a throw-in? I check two videos, then I try it outside."
There is no single right answer — your choice is what matters.
