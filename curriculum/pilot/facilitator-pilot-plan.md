# Facilitator Pilot Plan (सहजकर्ता पाइलट योजना)

> Purpose: confirm a **low-tech facilitator** can deliver one lesson using **only the facilitator guide**
> (`facilitator.ne.md`), with no author present. Capture gaps and improve the guide.
> उद्देश्य: कम-प्रविधि सहजकर्ताले सहजकर्ता निर्देशिका मात्र प्रयोग गरेर लेसन चलाउन सक्छन् कि भनी जाँच्ने।

---

## 1. Who & what (को र के)

- **Facilitator:** an NGO staff member or volunteer with **basic digital skills only**.
- **Materials allowed:** only the lesson's `facilitator.ne.md` (plus printed lesson if used in class).
- **Not allowed:** help from the curriculum authors during delivery.
- **Lesson:** pick one lesson; note its target outcome (O01–O12).

## 2. Before delivery (डेलिभरीअघि)

- [ ] Facilitator reads the guide alone and prepares the lesson.
- [ ] Facilitator can state, in their own words, the lesson's goal and outcome.
- [ ] Facilitator locates the offline alternative and the safety steps (SP-1…SP-5) referenced.
- [ ] Note any place the guide was unclear during preparation.

## 3. During delivery (डेलिभरीको बेला)

Observe (a second person takes notes; the facilitator just delivers):

| What to watch | Note |
|---|---|
| Did the facilitator follow the six sections in order? |  |
| Could they run the Practical Activity (and offline alternative)? |  |
| Did they handle the AI prompts and verify steps correctly? |  |
| Did they apply the right safety pattern when a risk came up? |  |
| Where did they pause, guess, or ask for help? |  |
| Did the tone stay supportive (no fear/shame)? |  |

Typical gaps to look for: missing step detail, unclear Nepali instruction, no fallback when AI/internet is down, unclear escalation, timing too long/short.

## 5. Debrief (छलफल)

- Ask the facilitator: what was easy? what was confusing? what was missing?
- Confirm whether the lesson's **outcome could be delivered using the guide alone**.

## 6. Feedback loop (सुधार चक्र)

1. Turn each gap into a concrete edit to `facilitator.ne.md`.
2. Apply edits; mark each gap row as fixed.
3. If gaps were major, repeat this pilot with a **different** low-tech facilitator.
